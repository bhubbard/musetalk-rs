01 // Cosine-Feathered 4×32×32 Latent Masking

Upper-face identity features ($y \in [0, 15]$) are preserved verbatim while lower-face mouth latents ($y \in [16, 31]$) are zeroed via contiguous slice fills and blended across a cosine ramp (`create_feathered_latent_mask`). 

let mask = LatentMaskGenerator::
    create_feathered_latent_mask(32, 32, 4);
orig_latent.blend_inpainted(&gen_latent, &mask);

02 // Whisper 384-D Phonemic Conditioning

Extracts 2-second Hamming-windowed spectral log-energy projections per 25 FPS video frame (`WHISPER_EMBED_DIM = 384`), feeding scaled dot-product cross-attention into the UNet mid-blocks. 

let feats = WhisperAudioProcessor::
    extract_whisper_features(&pcm_16k, 25.0);
let attn = SpatialAudioAttention::
    compute_attention_weights(&v, 64, &a, 64);

03 // BBox Shift & Temporal EMA Stabilization

Calibrates mouth opening amplitude via vertical pixel offsets (`bbox_shift`) and eliminates bounding-box jitter across frames using exponential moving average (`smooth_trajectory`) filtering. 

let shifted = FaceBounding::
    apply_shift(&bbox, -4, 256);
let stable = FaceBounding::
    smooth_trajectory(&boxes, 0.35);
